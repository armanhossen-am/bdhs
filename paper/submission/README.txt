BMC Medical Research Methodology - submission files
====================================================

Upload via the "Submit manuscript" button on the journal's website
(bmcmedresmethodol.biomedcentral.com), choosing the article type "Research":

  Manuscript.docx                         Main manuscript (title page, abstract, text,
                                          tables, figure legends, declarations, references)
  Figure1.tiff  (or Figure1.pdf)          Figure 1 - synthetic vs official estimates
  Figure2.tiff  (or Figure2.pdf)          Figure 2 - caesarean and facility delivery trends
  Additional_file_1_validation.xlsx       Additional file 1
  Additional_file_2_synthetic_fidelity.xlsx  Additional file 2
  Additional_file_3_data_quality.xlsx     Additional file 3
  Cover_letter.docx                       Cover letter (paste or upload)

Before submitting:
  - Read the manuscript critically and edit wording in your own voice.
  - Add co-authors (and update "Authors' contributions") if anyone else contributed.
  - Prepare 3-5 suggested reviewers (names, institutions, emails) if requested.
  - Software/code availability: https://github.com/armanhossen-am/bdhs
